# 三维色域原型（第一版）

记录于 2026-11-07。试验页面：`/colour/volume/`，尚未进入导航与目录。

## 1. 范围

第一版只做「归一化线性 RGB 色体」：

- 空间：sRGB、P3-D65、Rec.2020（三个都是 D65，先隔离几何与白点问题）
- 坐标：XYZ、xyY、Lab、Luv、Oklab、CAM02-UCS、ICtCp、JzAzBz
- 交互：拖动旋转、滚轮／双指缩放、双击复位、自动旋转
- 截面：按当前竖直坐标的水平面切开色体（着色器裁剪 + CPU 求交线）
- 显示：彩色表面（按 sRGB 预览色，超出部分裁掉）与中性表面两种

ICtCp、JzAzBz 与 CAM02-UCS 建立在绝对亮度上，需要参考白亮度（默认 100 cd/m²，可切换 48 / 203 / 1000），改变后重建几何；Lab、Luv、Oklab、XYZ、xyY 是相对体系，白恒为 L\* = 100 / L = 1，该控件在这些坐标下隐藏。

范围外（有意不做）：亮度／动态范围色体、ICC 配置文件色域、截面、点选拾取、色域叠加对比（后续单独做）。

## 2. 数据与数学

全部来自现有条目 front matter 的 `matrix`（RGB→XYZ，行 = X/Y/Z）和 `whitePoint`，没有新增数据源。

| 步骤 | 做法 |
| --- | --- |
| RGB→XYZ | 直接用条目的 `matrix` |
| Lab | 参考白取空间自身白点（当前三个都是 D65），不做色适应 |
| xyY | x = X/(X+Y+Z)，y = Y/(X+Y+Z)，竖直轴为 Y |
| 归一化 | 相对白 Y = 1；三轴等比例，不做拉伸 |

显示坐标（竖直轴在第二位）：XYZ → (X, Y, Z)，xyY → (x, Y, y)，Lab → (a\*, L\*, b\*)。

Lab 的参考白用**空间自己的白点**，不做 Bradford 适应：Nuke 的 Colorspace 节点默认 illuminant 就是 D65、Bradford 默认关闭，影视后期本来就这么用；D50 是 ICC／印刷体系的约定。代价是将来比较白点不同的空间（例如 ACES 约 D60）时需要另定一个公共参考白。

以主空间（网格 + 坐标轴）的并集包围球定中心与尺度，切换空间或坐标时重新定尺度。

## 3. 渲染

- WebGL 1，零依赖，`assets/js/colour-volume.js`（约 840 行）
- 六个面各切片成 N×N 网格（桌面 30，2× 屏 24），片元三角形约 1.1 万
- 法线用参数方向差分求出，再按各面「固定通道的正方向」统一朝向（按体积中心翻面会在折边处产生阶梯状着色）
- 不透明实体 + 深度测试；坐标轴、地平面网格、体表网格线用 alpha 混合叠加，网格线用顶点着色器里的深度偏移避免 z-fighting（不再沿法线抬起）
- 颜色：线性 RGB → 经该空间矩阵到 XYZ → sRGB 逆矩阵 → sRGB 编码，负值与 >1 直接裁掉
- 相机：透视 40°、环绕球坐标；近远平面随距离变化（避免背面 z-fighting）
- 标签（L\*/a\*/b\*、X/Y/Z、x/Y/y、W/K/R/G/B）用 HTML 覆盖层，每帧按投影位置摆放

一次重建（切换坐标或空间）约 **32 ms**，旋转与缩放不重建几何。

## 3.1 模型实现与校验

`assets/js/colour-models.js` 独立存放六个外观 / UCS 模型，全部与 `colour-science` 0.4.7 逐点对照：

| 模型 | 校验点（sRGB 红，Lw = 100） | 最大偏差 |
| --- | --- | --- |
| ICtCp（Dolby / BT.2100，PQ） | I 0.36379, Ct −0.10236, Cp 0.25842 | < 1e-6 |
| JzAzBz（Safdar 2017） | Jz 0.09896, az 0.09967, bz 0.09125 | < 1e-6 |
| Oklab | L 0.62793, a 0.22489, b 0.12580 | < 1e-6 |
| CIE Luv | L\* 53.2329, u\* 175.060, v\* 37.762 | < 1e-6 |
| CAM02-UCS | J′ 60.2007, a′ 42.0365, b′ 26.4892 | < 1e-6 |

CAM02-UCS 换了观察条件后也做了对照：平均环绕（La 20、Yb 20）与暗环绕（La 5、Yb 40）与 `colour-science` 完全一致；**昏暗环绕例外**——CIE 159:2004 的 N<sub>c</sub> = 0.95，而 `colour-science` 用 0.9，本页按标准取 0.95，因此 a′/b′ 会有约 3% 的差别（J′ 相同）。

观察条件（只影响 CAM02-UCS）：环绕可选平均 / 昏暗 / 暗（平均 1.0/0.69/1.0，昏暗 0.9/0.59/0.95，暗 0.8/0.525/0.8，按 CIE 159:2004）；适应亮度 L_A 取白点的 5% / 10% / 20% / 40%；背景 Y_b 取白点的 10% / 20% / 40%。默认平均环绕、20%、20%。

实现要点：JzAzBz 的非线性指数 p = 134.034（不是 1.7×m₂）。CAM02-UCS 的观察条件按 CIE 159:2004 实现，瞬时适应因子 D 与 F_L 随 L_A 变化。

## 3.2 截面

片元着色器按 `discard` 裁剪切面以上部分；交线在 CPU 上逐三角形与平面求交后单独绘制；背面着成浅灰，切开后看起来像实体的断面。

断面填充的做法是：把交线串成环、耳切三角化、按交点颜色插值填充。目前只在三角化面积与多边形面积相差小于 4% 时才启用，否则放弃填充（只保留浅灰内壁与交线）——sRGB 的 Lab 截面是不规则多边形，经常落在放弃分支，所以默认看到的多是内壁而不是平色断面。要稳定填平需要用模板缓冲（stencil cap），留作后续。
