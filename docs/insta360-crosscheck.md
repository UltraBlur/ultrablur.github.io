# Insta360 I-Log 页面数据的交叉验证

对象：`/colour/insta360-ilog/` 页面的原色、白点、曲线。
来源：Insta360 官方白皮书
`Insta360_10-bit_I-Log_白皮书.pdf`（v1.0，2026-06-10，5 页，SHA-256
`dd1b1353230092cd2a801d17d863866528e9d12351a314e6eca4dd8f0737ee11`），
从官方下载页 <https://www.insta360.com/cn/download/i-log> 取得。

验证思路同 vivo：**同一组数用两条路径各求一次**——一条抄白皮书，一条自己算。

---

## 1. 传递函数：逐字一致

白皮书 §转换规范 原文（第 5 页）：

```text
场景线性反射率 → I-Log            τ = 0.01104854
    out = α·in + β                  if in ≤ τ
        = δ + η·log10(in + θ)       if in >  τ

I-Log → 场景线性反射率            τ = 0.154402
    out = (in − β)/α                if in <  τ
        = 10^((in − δ)/η) − θ       if in ≥ τ

α = 5.77837328   β = 0.09055934   δ = 0.623992   η = 0.280055   θ = 0.01
```

页面曲线的实现与上表**五个常数、两个断点全部相同**，无一处改写。

## 2. 锚点逐一命中

白皮书正文表格给的是码值（10 bit）：

| 场景反射率 | 白皮书 | 页面曲线（连续值） | 取整 |
|---|---|---|---|
| 0%（黑） | 0.0905593 / **93** | 0.090559 (92.6) | 93 ✓ |
| 18% 灰 | **432** | 0.422003 (431.7) | 432 ✓ |
| 100% | **640** | 0.625202 (639.6) | 640 ✓ |
| 2200% | **1023** | 0.999999 (1023.0) | 1023 ✓ |

18% 的码值 432 对应 0.4220033，与白皮书表格一致。

## 3. 色域：白皮书直接声明 BT.2020

第 5 页「色域」一节写明：I-Log 的 RGB 原色、白点与各色度学转换均符合 ITU-R BT.2020。
其原色表（R 0.708/0.292、G 0.170/0.797、B 0.131/0.046，白点 0.3127/0.3290）与页面一致，
页面矩阵由这组原色按站点统一方法算出：

```
[ 0.636958048301  0.144616903586  0.168880975164 ]
[ 0.262700212011  0.677998071519  0.059301716470 ]
[ 0.000000000000  0.028072693049  1.060985057711 ]
```

## 4. 抓到一个我自己写错的数（已修）

上一版页面 intro 写「2200%（约 **+4.5 档**）落在 1.0」——错。
2200% 是场景反射率 22，相对 18% 灰：

```
log2(22 / 0.18) = 6.93 → +6.9 档
```

已改为 +6.9 档。这个错来自转述第三方整理时没有自己算一遍，正好印证"每条结论都要自己复算"。

## 5. 版本信息（值得记）

白皮书文档版本历史：

| 日期 | 变更 |
|---|---|
| 2024-09-20 | 初始化版本 |
| 2025-07-07 | **更新适用于 10 bit 容器的新传递函数** |
| 2026-05-20 | 文档润色及已知问题修正 |

也就是说 8-bit I-Log 与 10-bit I-Log 的曲线不是同一条；本页采用的是 10-bit 版。
官方下载页把两者分开列（8-bit 只提供 LUT，10-bit 提供 LUT + 白皮书）。
